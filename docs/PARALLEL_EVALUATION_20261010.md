# 两路独立测试调度

用户授权在资源充裕时并行测试。本次仅改变执行调度与缓存文件安全性；模型、Checkpoint选择、Episode、数据、成功半径和指标分母不变。最多两个独立评估同时运行，任何训练任务都形成队列屏障，不能与该队列其它任务重叠。当前已启动的phase22顺序队列不重启；未启动phase22b等待队列将保留旧等待状态后由新调度器接管。

代码检查发现两个必要修复：`atomic_save`固定`.tmp`文件会被两个缓存写入者竞争；瞬时ROI PNG按像素key共用文件会被一个编码器删除、另一个尚未读取。现在每次保存使用独有临时文件、完成后原子替换；每次观测使用私有临时ROI目录，并自动清理。共享缓存仅保存真实当前像素生成的冻结特征，键仍为像素SHA与模型协议，未增加未来观测或目标标签。特征精度、ROI像素生成和网络前向路径不变。

回归测试强制两个写入者同时发布同一特征，验证载荷可读且临时文件清理；强制慢编码器在快编码器完成清理后才读取自己的相同像素ROI；调度器测试验证两个评估确实重叠、训练等待二者完成、下一评估等待训练结束。全部144项测试通过，见`reports/sbf_protocol/pytest_20261010_parallel_eval.txt`。

源代码每任务独立快照。队列记录PID、起止时间、实际返回码、并发上限和原始/执行命令；失败后停止新任务，保留已启动独立任务的真实结果。文件锁防止重复调度器，输出、日志和任务名必须唯一；仅允许显式恢复空的waiting状态，不自动重启正在运行或已完成任务。

最终候选仍须在任何新GraphNav Unseen之前冻结并Commit权重SHA。冻结清单记录`evaluation_workers=2`及评估并发元数据。并行推理延迟受到其它进程竞争，不能与历史独占SBF延迟宣称公平加速；导航SR/SPL等协议不变。设备级GPU监控在重叠时间窗内是整体利用率/显存，不是单模型独占统计。冷/热缓存与独占/并行结果分别标注。
