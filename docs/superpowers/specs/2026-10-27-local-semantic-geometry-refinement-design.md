# 语义与 box—参照物几何关系驱动的局部精修设计

日期：2026-10-27。状态：设计提案，未实现、未训练。该设计替代早先将新分支泛化为三维重建/通用高度筛查的设想。数值配置是设计者给出的首版默认值，不是已验证最优值。

## 1. 目标和职责

冻结论文主模型，保留原 28×28 二维热图及原控制器。新分支在主模型多个峰的局部邻域内，依据“指令语义—候选 box—参照物关系”重排实例，并输出有界局部 XY 精修。深度/高差帮助关系判断；不输出未经核实的绝对目标 Z，不修改飞行高度控制。

首版采用轻量语言条件关系 Transformer，不微调 WALDO、SigLIP 或 BERT。选用它而非当前八维标量 MLP，是为了保留完整视觉和 token 语义，并让每条候选—地标关系直接受指令条件化；相较大型 VLM 或完整三维网络，训练和因果消融更清楚，且适配现有监督。训练输入全部来自公开信息与当前观测，目标 ID/坐标/轮廓只存在 labels 中。

## 2. 已核实的数据条件

- CityNavRecord 含 instruction、object_id、description_id、target_position、trajectory；CityRefer 对象含 object_type、position、dimension、contour、name。
- processed_descriptions 仅有 target、landmarks、surroundings 等字段；没有已核实的完整关系词 span、颜色属性或场景图真值。不能假称这些监督现成存在。
- referenced_landmarks 是原基线公开输入，来自 processed description 的地标链接；使用这些链接属于相同 benchmark 设置，不代表部署时已解决开放地标识别。公开名称匹配仅作候选解析，不允许用目标 ID 查询线上参照物。
- 当前深度为正射图/DSM 派生的垂直深度代理，支持可见表面高差，不是完整三维/遮挡观测。dimension.z 是垂向尺寸，不等于世界高程或离地高度。
- 旧缓存 764 train /96 dev 中，有高差监督的视图为65/7；仅保留图文相似度标量、最终top16候选，无法训练本设计，必须以新 schema 重建。

## 3. 候选与参照物构建

主热图取最多3个空间分离峰。局部搜索半径初值40m，峰间分离下限一个实际栅格对角线；这些配置在训练内部校准后冻结。局部邻域取并集，WALDO 可以检测整个当前视野，但仅将邻域候选交给精修分支；位于视野外的热图峰保持原样。

首版候选覆盖 WALDO 可检测的车辆/建筑实例；线上始终只依据指令、候选及matchability门控，禁止读取目标GT类别决定启用。训练包含不能匹配的任务以学习回退；不能保证仅靠语言已能完美识别不支持类型，因此所有任务都评测，按GT类别的支持/不支持分层仅在离线报告中进行，并报告误启用率，不从论文评测集中删去。最多32个候选，以三路交替取样去重：主先验、冻结图文语义匹配、空间分散；每路不足则补其他路。所有截断前检测、中心/边界过滤与最终候选 ID 都缓存，检测缺失时不注入 GT box 作为线上候选。RGB有效、深度缺失的框仍保留。

参照物最多16个，优先保留公开指令链接及原主模型一致的打包顺序；若超限记录截断、回退不完整关系。参照物可位于目标局部邻域之外。保留轮廓与名称，即使当前视野看不到它，仍可使用公开 XY 关系；其 RGB/深度标记缺失。

参照物 XY 统一采用公开多边形的面积质心；退化轮廓用包围框中心。训练真值关系和线上关系使用同一原点，禁止一处用顶点均值、一处用对象 position。道路/大型参照物额外保留到轮廓最近距离，避免只有质心距离。基于公开 footprint 的几何有效性与基于当前观测的深度有效性分开。

## 4. 输入合同

每个样本是一次观测，padding 到 B×N×L，N≤32、L≤16、文本T≤96。离线缓存应存未归一化物理量、原始有效性与 schema/hash，归一化由模型配置固定。

| 输入 | 形状（单观测） | 来源与用途 |
| --- | --- | --- |
| instruction tokens | T×768、T mask | 现有冻结 BERT，保留逐词语义 |
| candidate RGB features | N×D_rgb | 冻结 SigLIP 同一 native processor 的 box crop pooled向量，保留完整向量；D_rgb从配置读取 |
| reference name tokens | L×S×768 | 同一BERT编码名称；S≤32，并保留名称mask |
| reference RGB features | L×D_rgb及mask | 当前可见参照物局部crop；未知置零并带mask |
| depth patches | (N+L)×2×32×32 | 通道为有效surface_z相对当前视图稳健基准的差值及有效mask；无效数值置零；数值除20m并裁剪到[-5,5] |
| node geometry | N/L×配置维度 | 世界XY、box尺寸/面积/检测类别和置信度、观测覆盖率、surface_z统计与有效性；主先验作为单独特征 |
| relation geometry | N×L×G | 以下定义的水平/垂向关系及独立有效mask |
| baseline field | 784 logits与世界XY | 原28×28先验，用于局部范围、上下文与反馈 |

深度基准为当前合法表面样本的p10，只作数值中心化，不解释为地面。保留原世界surface_z及分位差等元数据，以计算参照物高差。候选和参照物都采用可比较的观测支持定义，禁止 box 中位数无条件等同物体顶面；检测框只是粗支持，不是精确实例分割。

统一表面采样算子：将每个支持区域（检测框、公开参照物轮廓或仅标签中的目标轮廓）在当前观测分辨率栅格化，以边界框短边5%（至少1像素）为半径向内腐蚀，若腐蚀为空则未知。裁剪到FOV后须保留腐蚀前完整支持的至少80%；其中合法深度/RGB像素比例至少70%，至少4个有效样本，且p90−p10≤8m，才输出有效样本surface_z中位数和spread；阈值是首版保守初值，按训练抽检确定。其余均未知。部分可见时输出仍只称“当前可见内收支持表面的中位数”，不解释成完整地标顶部；两端分别带支持类型/可见率/误差，支持语义无法核对则Δz未知。算子一致并不能消除检测框与粗GT轮廓的差异，因此对应高差始终是弱监督，不作硬排除依据。patch采样也保留同一支持mask，不把框外背景当有效目标深度。

缓存保留绝对世界坐标用于投影/画图；送入节点网络的XY统一为(position−当前相机XY)/R，候选与参照物共用同一原点。网络不读取map_id、target_id或绝对城市坐标，整体世界平移（含相机/目标/地标）后归一化输入应一致；不要求只移动某个物体时保持不变。

候选 i 和参照物 j 的基础边特征为：dx/R、dy/R、sinθ、cosθ、log(1+d)/log(1+R)、到轮廓最近距离/R、候选中心是否在参照物区域内、相对box尺度、同定义surface Δz/20m、atan2(Δz,d) 的sin/cos，以及各项有效性和误差尺度。R是固定局部归一化尺度；过近时方向和仰角标未知。距离通道必须进入网络并有回归探针。

世界“东/北”与图像“左/上”不能混同。由已知投影转换提供世界/图像两套方向特征及坐标系标记；“我的左侧”等相机/观察者关系无可确认姿态时不生成硬监督。坐标转换单位与朝向在缓存审计中验证。

“A和B之间”额外使用候选—双参照物三元关系：沿AB的投影参数t、到AB线段的归一化垂距、(dA+dB)/dAB及有效性。先对L≤16全部非退化参照物对编码，再由文本注意力选权，不强迫二元关系平均模拟“之间”。

## 5. 网络结构

所有新增隐藏维度256，注意力4头、dropout0.1。参数量以实际实例化统计为准，不预先声称训练规模或速度。

1. **视觉/深度节点编码**：冻结SigLIP向量投影至256；深度CNN使用3层3×3卷积（2→32→64→128，stride2、GroupNorm、GELU）和全局池化，再投影至256。将RGB、深度和节点元信息拼接经MLP形成候选/参照物节点，缺失模态使用mask和学习的缺失标记。
2. **语义交互**：BERT tokens投影至256。候选节点和参照物节点各自对完整指令做Cross-Attention，保留目标属性、地标指代与关系词的上下文；名称tokens单独池化后加入参照物节点。无需假设已有人工场景图或颜色标签。
3. **关系编码与融合**：MLP编码完整边特征；将候选节点、参照物节点和边embedding组成edge token，对指令Cross-Attention。候选对其有效edge tokens做文本条件注意力汇聚，加残差更新候选节点；重复2层。双参照物关系通过独立MLP编码、对文本注意力，再汇入候选。保留null-reference以支持无地标指令，不能将全padding交给attention。
4. **输出头**：候选rank logit；每个候选的局部偏移Δxy；观测级是否存在可精修匹配的matchability logit；逐候选参照物注意力供诊断。注意力不是已验证解释或概率真值。
5. **辅助期望关系头**：由指令条件化的参照物节点预测目标相对该参照物的方向向量、log距离和可用时的surface Δz；该头不读取当前候选边几何，避免直接复制输入。其输出与每个候选实测关系的残差/可用性作为下一层edge输入。方向与距离是软预测，不将模糊语言强制量化为精确规则。无可靠高差监督则停用对应辅助loss，不阻断主排序训练。

预测几何、实测几何与语义edge表示共同进入候选评分。外部角度若实际线上可得，使用独立 external_relation_input（来源/误差/mask）；首版默认禁用。不能把训练 target→landmark 真值当作已知推理角度。

## 6. 输出与接入

逐候选输出candidate_id、rank logit、Δxy、参考关联权重和观测有效性；观测级输出matchability。Δxy通过tanh约束在候选框扩展邻域内：每轴上限为box世界尺寸的1/2加2m，并最多8m；位置还须落在合法可见支持与局部搜索范围内。框中心只是起始假设，精修位置监督沿用CityNav目标XY。

matchability只表示“当前候选是否可供局部精修”，不声称物理目标不存在。只有经训练内部校准且达到适用条件时启用反馈；否则原GoalField精确回退。

热图反馈采用可审计的归一化局部混合：令S为候选box并集膨胀2m后、可见有效RGB支持、且属于局部搜索邻域的栅格中心集合；低分辨率下某box不含栅格中心时，仅可将其映射到局部邻域内最近的合法栅格并记录量化误差。Q在S上由候选softmax权重与各候选修正位置的局部核构造、归一化；核只传播到该候选支持区域，不跨全图。基准P0=softmax(logits)，m0=ΣS P0：

- S外：Pnew=P0；
- S内：Pnew=(1−α)P0+α·m0·Q；
- α∈[0,0.5]，由校准后的matchability门控，校准阶段从固定小网格选强度；S为空或无可信匹配时α=0并直接返回原对象。

这样保留局部总质量和全局未观测区域，只在候选之间重新分配概率。使用log(Pnew)重建原GoalField、保持上下文重排一致，并沿用当前在原控制器之前注入的hook；每步控制器和记忆提交一次。首版轨迹控制目标仍是28×28栅格，细粒度XY输出先用于局部核和独立误差评测，不能宣称原控制器已具备亚栅格导航精度。若要实际消费连续XY，另设后续实验，不能混入原论文主对照。

## 7. 真值与缺失监督

| 输出/任务 | 真值来源 | 资格与边界 |
| --- | --- | --- |
| 候选排序 | target object ID对应的类别/公开对象轮廓/target_position[:2]，离线关联检测框 | 关联不明确则屏蔽；不能仅距目标8m就认定同一车辆 |
| 局部XY偏移 | target_position[:2]−候选中心 | 只对可靠正候选、真值在偏移可达范围且观测支持有效时监督 |
| 期望方位与距离 | 目标XY和一致定义的公开参照物XY，几何计算 | 仅训练标签；目标与参考过近时方向未知；公开链接和别名解析不可靠时屏蔽 |
| 目标—参照物surface高差 | 当前观测中目标GT粗轮廓与参照物同定义有效表面统计 | 弱监督、单独报告覆盖；不等于真实物体顶部，不能作为已验证3D真值 |
| 地标指代/名称关联 | 原processed description公开地标链接 | 可监督有链接的名称集合；没有span/同名唯一对应时不硬造token对齐真值 |
| matchability | 离线判定当前最终候选中是否存在可靠可精修正候选 | 只有完整覆盖且关联可判定时设0/1，否则未知，不是物理存在标签 |

离线候选关联规则：先映射到世界坐标，将目标及周边标注轮廓栅格化，做类别兼容的box—对象空间匹配；保存IoU、归一化中心距离、最近/次近对象差距和歧义。首版高可信规则为IoU≥0.5、中心距≤对象包围框对角线的0.5倍、且与第二对象的IoU差≥0.15；该规则是待训练集抽检验证的初值。未通过不直接当负例；只将明确对应其他已标注对象的框作为强负例。标注轮廓过粗/多框覆盖时可多正例软归一化，仍保留置信权重；无法确认则跳过相应监督。抽检不通过时先修订规则并重建缓存，不能用论文Val调整阈值。

人工抽检初始100个检测—对象关联对，覆盖车辆密集/建筑边界/多目标/深度缺失场景；这是建议预算而非已做结果。抽检不能通过则禁止宣称实例筛查提升。不需要新增整套人工颜色/关系词标签，首版从现有目标关联和几何监督学联合匹配；若加入规则生成的关系词/span，仅作弱标签且独立标记来源。

## 8. 训练步骤与损失

按(map_name,object_id)分组形成train/internal-dev/calibration，目标实例不跨集合；同一对象的全部description_id和视图归同组。先在原256任务的可用实例上建立正确性pilot，再扩充训练分区；不能把860视图当860独立目标。校准集从原训练目标组中预留15%（seed17），原32任务internal-dev不变，论文Val不参与选模与校准。

观测初期使用专家轨迹的多时刻快照；第二轮补入冻结主模型rollout真实错误附近的观测，按相同规则离线关联，避免只在理想轨迹训练。记录目标不在候选/视野中的样本以学习回退，不注入oracle正框。困难负样本优先同类别、视觉相似但关系不符，及关系近似但视觉不同；无可靠实例身份不参与强排序。

冻结WALDO、SigLIP、BERT和主模型；只训练深度CNN、投影层、两层关系网络和各预测头。离线缓存冻结编码特征，以免每步运行大编码器。

第一阶段训练排序和关系，20 epochs作为pilot上限、batch8（变长padding）、AdamW lr3e−4/weight_decay0.01、5%warmup、梯度裁剪1、seed17；按实例均衡采样，不能让某条长轨迹主导。初始loss：

`L = Lrank + 0.2·Langle + 0.1·Ldistance + 0.1·Lsurface + 0.2·Lmatch`

Lrank是标签有效候选上的多正例soft-target交叉熵：独立rank_label_mask只包含可靠正候选与明确对应其他实例的强负候选，softmax分母仅在该mask内计算；身份未知候选不进分母，仍保留推理候选。没有可靠正例则跳过该样本Lrank，只有正例没有负例时不声称产生了有效对比训练。Langle用方向归一化后的1−dot；Ldistance用固定尺度归一化log距离的SmoothL1；Lsurface用Δz/20m的masked SmoothL1；Lmatch是资格明确样本的BCE。各项只对自身有效样本平均，无标签项为0，不伪造负例。

第二阶段从第一阶段选中权重加入偏移头，再训练最多5 epochs：`Ltotal=L+0.5·Loffset`，Loffset对归一化Δxy使用masked SmoothL1，仅可信且可达的正候选参与。epoch预算是起点，记录实际更新数与有效标签数。网络及反馈均不使用28×28热图CE作唯一优化目标；首版反馈采用解析混合与独立校准，不再加一个不易解释的热图生成大头。

每epoch内部验证候选Recall@1/MRR、关系误差、局部XY误差以及相对原候选top1的修正致错率。首版选模：对原top1正确样本不得新增错误；满足者中优先rank@1、再MRR、再局部XY误差、再较早epoch。若无权重满足，保留为诊断，不启用反馈；报告该严格门槛的小样本局限，不称其为总体风险保证。

最后冻结模型，在独立calibration上校准matchability温度、门限和α（候选网格0/.1/.25/.5），以优先保留原正确候选、再提高错误样本修复率；无可用样本则不启用。选模与校准分离，所有决定在论文Val前冻结；正式结论需要多随机种子和目标实例级区间。

## 10. 验证和展示

先确认实例关联、候选coverage、方向坐标和高差定义，再运行真实样本前后向。单元测试只能验证程序行为，不能证明语义理解。

必做消融：RGB+language、RGB+depth+language、去关系、去语言（使用同一中性embedding而非全mask）、只去高差评分、清零/打乱有效深度、去局部偏移、只用主先验。缓存中有有效高差的子集独立报告，避免大量无高差样本稀释结果。

语义反事实需固定场景改变参照物/方向后重新核实目标或标为无匹配，不能机械替换词后沿用GT；几何反事实固定语言和RGB，改变与已验证关系有关的几何，检验分数排序变化。未知数值填充、候选/地标重排、局部坐标整体平移不应造成非法变化。世界方向词下不能随意旋转场景却保留文字。

展示图包含指令、原热图、候选/参照物ID、几何连线（角度/距离/有效高差）、关系评分、修正前后局部热图及真值标记。GT只在离线绘图层显示。成功和失败样本按固定规则选取，不只展示好例子。额外统计不同实例映射同一28×28格的比例、量化误差，以及“候选重排成功但栅格未改变”的次数，明确局部识别改善为何未必转成导航改善。

闭环仍以原Seen128/Unseen128配对任务作pilot，报告XY SR/SPL/NE、修复/致错任务数、完整观测+检测+编码+分支耗时。无覆盖的目标类型计入全量评测和回退/误启用统计，并额外给支持类型子集。未增加实际垂向任务/真值，不报告“3D导航成功率”。
