# Observed visual grounding data

`render_full_observations.py` uses every original Revised CityNav Train/Val Seen/Val Unseen episode, at fixed trajectory steps 0, round(0.5*(length-1)), and round(0.8*(length-1)). The camera selection never reads the destination or target geometry. These are offline human trajectory prefixes, not policy observations. Frames are the existing native 384 CityNav nadir renderer's current RGB crops; full rasters stay inside that renderer.

`build_parallel.py` runs six map-disjoint workers with CPU library threads limited to one. All CityRefer polygons are audited; model regions cover all original task target classes Building, Car, Ground, and Parking, including unnamed objects. `fast_projection.py` duplicates the existing projection arithmetic after catalog polygon validation. A preserved random 500-case comparison includes accepted and rejected regions.

All valid geometric ROIs are indexed. PNGs are materialized for each object's first two distinct camera footprints at native minimum bbox side 24 pixels, and for language-supported candidates in an eligible target query frame. Other rows retain source frame, bbox, footprint, and a nullable image path. Geometry is in `objects.json`, indexed by map and object ID. IDs are offline annotation links and are excluded from encoder inputs.

`audit_attributes.py` binds adjacent target noun attributes only from CityRefer's processed `target` field. `surroundings` colors are not assigned to the target. Conflicting attributes across target descriptions are unknown. Consistent language labels are weak supervision, **not independently image-verified labels**. Building size and surrounding context are unsupported. `build_candidate_sets.py` excludes unknown attribute candidates and permits every supported matching attribute object as a positive. Candidates come only from the same episode's observations at or before the query cutoff. Train subsets use a deterministic map/200 m spatial-cell hash; every object's views stay together.

`build_cases.py` makes 150 map-balanced Train/Seen examples, with the current source frame's projected polygon/bbox beside the actual ROI. Each object's highest native resolution observation is preferred. Diagnostic agent review does not establish independent human ground truth. `summarize_audit.py` separates projected-region coverage, materialized-image coverage, weak labels, and independent attribute verification.

The full dataset is generated by:

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python experiments/visual_grounding/data/render_full_observations.py
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 python experiments/visual_grounding/data/build_parallel.py --workers 6
python experiments/visual_grounding/data/build_cases.py
python experiments/visual_grounding/data/summarize_audit.py
```

The rendering stage writes `data_audit/full_observations`; deterministic full indexes are in `data_audit/full`. Interrupted broader auxiliary-region attempts are explicitly retained as partial files and are excluded from the benchmark indexes.
