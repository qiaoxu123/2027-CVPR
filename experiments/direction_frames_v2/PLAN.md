# CityNav 参考系续验 v2 计划

**Goal:** 在不预设统一约定成立或不成立的条件下，复查v1的实体/作用域/几何与参考方向，比较高置信和完整有效集。
**Base:** e6ddb0986b03ac5402894e0f71ffb1f388e513d2, experiment/citynav-direction-frames-20261106。
**Execution:** 本会话原生顺序执行。当前工具不支持切换 Plan Mode，以此文件记录计划。用户消息在“Polygon PCA 主轴具有”处截断，已请求补充，先执行不依赖缺失内容的工作。

## 不变量
- 仅 original CityNav TRAIN 和原始 CityRefer；不读 Val/Test，不训练，不修改 Geometry/Relation/PGVB。
- 绑定模块只接收文本和对象 ID/name/type，不接收目标 GT、轨迹或任何几何距离；重复同名不按目标位置消歧。
- 无方向符号的 PCA/轮廓轴同时保留两个符号，不能逐例取与目标最匹配的符号作为独立成功率。
- 运动方向的未来段仅离线诊断；接近目标段是额外 target-GT-conditioned 诊断，不能用其高匹配率证明描述参考系。
- 保留v1结果作为历史，v2另存，不覆盖旧统计。

## 任务
- [x] 四组案例：原始6条描述/索引、同名实体全表、真实地图、完整轮廓与邻域、视角语句、轨迹代理；分别判定绑定、作用域、视角、真实矛盾是否可识别。
- [x] 覆盖率漏斗：复现原解析错误/漏检，加入文本依存分析和可审计规则，记录 named NP、关系主语、依存路径、置信等级、排除原因；高置信须独立句法证据一致。
- [x] 有效集分层：高/中置信绑定、direct/indirect/nonrelational、Polygon完整边界/重叠，GT不在Polygon时保留异常而非修正绑定。
- [x] A：四轴、90/180/270旋转、X/Y镜像、统一图像轴（等价关系清单）；联合词典评分，不逐词任意选轴凑一致率；TRAIN分组交叉验证选择全局变换。
- [x] B：start→reference 与 reference→start；所有方向词用真实绑定参照物。
- [x] C：初始yaw、首段真实运动、到参照物最近接段运动、到目标最近接段运动；记录方向获取窗口、可用性、未来信息/GT条件化标志。
- [x] D：具名道路局部切线/双向轴、明确绑定的停车场车行/排列方向、建筑轮廓轴；有向heading仅可靠独立标注，缺失则不可评估。绘制±符号敏感性及无向轴统计，禁止GT选符号。
- [x] 汇总各集一致率/角偏差/覆盖率/cluster 95% CI、共同支持集、地图/目标类别分组及局部/视角提示分层；图表全用真实TRAIN。
- [x] 复现实验、作用域反例测试、全量源记录校验；实际调用 adversarial-review，记录真实审查状态；更新中文报告、CHANGELOG，commit+push原实验分支。
