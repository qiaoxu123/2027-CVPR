# 追加：仅视觉、名称输入，几何分支严格关闭

用户进一步要求：输入依然只是地标名称，不依赖几何分支。继续同一64个名称任务、起点、原生yaw、RGB与Checkpoint；不改模型参数或训练。

**E3_visual_only**：不执行A3，不提供具名Polygon、名称到地图绑定、原任务GT或Oracle点；起始空间先验均匀。原SigLIP编码、原matcher、原质量历史、原视觉增益及有界公式保持原值。未观测区域保持未知/中性。只使用名称文本、当前及历史真实RGB、相机位姿及地图边界完成观察到世界网格的映射。几何分支设置运行时拒绝hook，任何A3 forward都报错；每步记录调用数必须为0。

原Trajectory/Stop还会读取A3 dense candidate_context，因此这一项也必须移除，使用明确的中性零值，而不是偷偷保留几何上下文。仍用原head权重和Guarded-Blend/BoundedWaypointController，不改变阈值。该零上下文是消融接口，不是伪造的视觉特征。

**E1_neutral_context控制组**：使用同样零上下文/不执行A3的接口，但给予公开Polygon Oracle Goal。此组仅用于判断移除上下文本身是否让控制头无法到达正确点；不是正常视觉成绩。

两组均补齐64条，不根据结果改增益、先验、Stop或文本。E3是原本联合训练的视觉残差分支在均匀先验下的冻结消融，并不是经过独立训练的视觉导航模型；负结果不能推广为“视觉导航不可能”。名称通常不直接描述外观，已知名称→地图位置这一信息在本消融中被刻意关闭。结果需与E2完整模型并列，Polygon只作E3事后评价。
