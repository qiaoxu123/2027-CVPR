# 第二阶段：固定yaw真实采集与局部匹配机制实验

## 结论

**确定存在ROI支持缺口；尚未证明关系链文本能稳定改善视觉定位。不能据此启动Val128或宣称SR提升。**

24个TRAIN物理实例，16张地图，Car/Building/Parking/Ground各6个；按轨迹索引均匀采4个时刻，短轨迹去重后87帧。参考轨迹用于采集，不是闭环导航。相机yaw固定0，agent yaw不变，XYZ不变；384px由原始栅格重新采样，不是旧图旋转/放大。最大像素—世界往返误差0.00892px。图像/depth/输入SHA、模型SHA及独立公开输入/训练标签已保存。

所有语义角色由当前会话AI从原文整理，原指令完整保留，不调用Qwen或外部API。任务列表中也显示了类别和实例分组，因此不是严格盲解析准确率评估；文本推理模型仅接收文本、当前图像特征及公开坐标，不接收类别/实例ID/GT位置。没有人工像素框；全87帧真实可见性和实例匹配金标准未知。以下20m统计仅为世界位置代理。

## 1. ROI支持

同一批87张真实图像、同一模型、同一全局28×28候选坐标，仅改变实验ROI尺度；未改原默认编码器。

|统计|原32/64/128m|实验8/16/32m|
|---|---:|---:|
|完全没有有效ROI的帧|22|13|
|GT点位于Footprint且该点有深度代理支持|42|42|
|上述42帧中仍无任何ROI|10|4|
|存在20m内有效网格候选的帧|25|38|

原规则要求整个ROI位于图中、深度有效比例≥90%、像素跨度足够且有patch支持。低空视域不足32m时，原最小ROI就可能完全无效。更小ROI能恢复支持，但不能保证正确实例被识别。剩余无ROI还需检查网格间距、边界、深度和屋顶高度等因素，不全部归咎尺度。

## 2. 冻结匹配结果

不训练。分别运行预测命令、封存输出SHA，再由独立评分命令读取TRAIN目标位置。全文查询保持原完整文本加appearance_query；分角色查询拆分目标外观与参照描述。scope_multiscale是小ROI目标分数+0.5×大ROI参照分数，0.5在评分前固定，只是机制探针，并非完整关系推理。

|配置|87帧空间Top1命中数|共同有几何支持25帧Top1|共同25帧局部NE|
|---|---:|---:|---:|
|原ROI + 原全文|3|3/25|77.58m|
|小ROI + 原全文|11|4/25|74.42m|
|小ROI + 目标外观文本|13|6/25|90.30m|
|小ROI + 分尺度目标/参照|11|5/25|88.78m|
|小ROI + 全文 + 打乱RGB|11|5/25|83.70m|
|小ROI + 目标文本 + 打乱RGB|11|5/25|85.92m|
|小ROI + 分尺度 + 打乱RGB|10|5/25|82.02m|
|小ROI + 全文 + Zero RGB|10|5/25|92.82m|

- 小ROI全文相对原ROI全文，87帧配对新增8次空间命中、丢失0次；但主要伴随支持集合扩展，且随机对应/零向量控制仍有相近命中数。不能将其归因成已证实的视觉识别收益。
- 同一小ROI、同一87帧，目标文本相对全文纠正3、误改1，净+2；分尺度方案纠正2、误改2，净0。这里“纠正/误改”只指局部候选的20m代理，不是A0或最终Belief纠错。
- 小ROI目标文本虽然Top1稍增，NE更差。分尺度目标/参照不稳定优于目标文本，不能直接推广“关系链有效”。
- 全87帧包括目标区域未被观察到的时刻；无ROI时记录弃权，不能计为检测失败。共同25帧也仅有几何支持，不等于真实可见。
- 原/小ROI可产生预测的帧数分别65/74，所以不能直接比较各自条件NE。表中NE严格使用共同25帧；完整JSON另存各自条件统计。
- Car在22个采样帧中，原ROI全文1次空间命中，小ROI全文3次、目标文本4次。不是车辆实例准确率，样本太少且未独立确认。

## 3. 真实图像例子与20m指标风险

[24实例HTML图册](cases/index.html)按每个任务最后一个已采集时刻展示，**不按成功挑图**。绿色仅表示GT世界点投影，红色表示局部候选中心，没有伪造像素GT框。

例如train_00545：原ROI无候选；小ROI恢复2个候选，但最终红点在车旁道路上，离GT约7.3m。虽然满足20m代理，不能说明找到了指令中的灰车。这是需要训练细粒度位置判别、并额外核验实例身份的直接例子。

## 4. 下一步决策

1. 不把scope_multiscale冻结分数规则作为最终方案，不扩大正式Val测试，不继续搜索其权重。
2. 最有证据的工程改进是**保持近目标时的有效局部观测支持**。后续采用观测内局部候选/自适应尺度，避免只依赖稀疏全局网格和最小32m完整ROI。
3. 在此基础上训练轻量局部位置分布头，分别输入目标外观、中间区域描述及公开地标几何；全局先验保持原样，未观测区域保留未知。目标世界位置用于Goal损失，不冒充像素实例正标签。使用非残差位置分布与原有界残差作对照。
4. 本24例已用于开发，不用来宣称泛化或选择正式配置。新训练拟合/独立确认必须按物理实例、episode及地图分组，先做真实GPU Smoke和预算测量，并保留Zero/Shuffle视觉对照。
5. 独立TRAIN的定位与保真有可信收益后，冻结模型再运行128条Val-Seen真实配对闭环。用户门槛是SR严格>65%，即至少84/128，并有相对基线收益才扩大完整测试。

## 5. 实测开销与测试

采集87帧8.54秒（已装入数据后的采集循环）；原ROI冻结编码3.72秒，小ROI3.42秒（均不含模型加载），峰值GPU allocated约3.38/3.39GiB。只能代表本批RTX PRO6000上的编码循环，不是导航单步端到端时延，也不是完整训练耗时。

原权重未修改，无AerialVG，无Val/Test新访问，无导航训练或控制器变更。相关17项测试通过（含相机/agent姿态分离、Footprint往返、低空ROI几何支持、原Stage1/匹配头）。尚无新训练Checkpoint或新SR。
