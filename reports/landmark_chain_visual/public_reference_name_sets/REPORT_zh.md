# 公开地标名称集合与参照监督覆盖审计

2026-11-04。只读现有固定相机yaw=0的TRAIN-fit900帧及TRAIN-dev92帧公开观测/冻结特征。未训练、未读取目标私有标签，未改变正常推理、权重或控制器，未访问Val/Test。

## 实际发现

旧审计只保留名称唯一对应一个公开对象ID的匹配，遗漏fit698、dev70个多ID名称-帧关系。新审计保留全部同名对象为独立候选，不合并轮廓，不选择距离目标最近的对象。

最后一行只是复用现有project_landmark门槛的几何ROI支持，不包含RGB支持率、深度支持、ROI编码或人工可见性核验，不能当成完整current_landmark_rois输出。不同支持条件不是互相包含的集合。patch仍使用原有90%内部覆盖、2m边界不确定带、质量有效性规则。

“仅单ID”仍比旧报告的参照-帧条目多，因为本审计未沿用旧脚本仅四种object_type的限制，并以名称-帧组计数而非去重ID-帧；不可直接比较条目总数。上述数字均为各口径自身去重后的帧数。

## 多ID不全是假歧义，也不全是同一实例

fit698个多ID名称-帧组中：104组是规范名称及类型一致的TrafficRoad多轮廓，46组是其他同名同类型多轮廓，548组存在名称或类型替代。dev分别0、4、66组。这是重复帧上的组数，不是独立实体数量。

实际例子：
- Panton Street对应9个Footpath/TrafficRoad对象；Trumpington Street对应Footpath/TrafficRoad。
- Fitzwilliam Museum同时对应Building/TrafficRoad。
- The Coppice、St Peter’s Terrace同时对应Building/TrafficRoad。

因此，直接丢弃多ID名称会损失公开参照覆盖，但将其全部作为确定实例正标签也会引入错误监督。道路轮廓不是已经核验的道路中心线；本审计不推断道路拓扑。

## 决策与下一步

已有单ID监督覆盖低估了可用参照，但较大7-patch仍缺少精确地标支持；新增候选只提高几何可观测上界，没有证明视觉关系泛化。暂不重跑全球证据网络训练。

下一步应先对真实当前RGB验证同名多轮廓与ROI配准，采用公开类型/语言角色约束保留候选集合与弃权；同名多候选不能强制单实例监督。随后从官方TRAIN轨迹按公开参照与Footprint支持采样，不能按目标GT邻近选择。确认参照视觉证据足够后再设计集合级训练，并保持真实RGB/打乱RGB/无视觉对照。最终仍以导航SR门槛为准。
