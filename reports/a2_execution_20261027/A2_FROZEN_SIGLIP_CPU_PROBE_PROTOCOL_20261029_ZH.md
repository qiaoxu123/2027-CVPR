# 固定图文匹配CPU可行性检查

在读取本次结果前固定以下检查方式，不修改正在运行的V4实验。

假设：同一冻结SigLIP2模型的文字与候选图片相似度，可能提供当前新增BERT—图片排序网络之外的可用信息。这里只检验直接使用完整指令的可行性，不预设会提高指标。

范围：当前角色文件中全部2,025条自主行走TRAIN观测，以及1,029条自主行走内部DEV观测，共3,054条。排除参考路线观测、独立校准及正式Seen/Unseen观测。

固定方法：

1. 校验原A0权重SHA；从其协议读取SigLIP2名称与版本，CPU加载原冻结图文模型，检查版本与全部参数冻结。
2. 以原始完整指令调用已有冻结文字编码接口。采用原接口的固定最大长度和截断；不根据答案改写指令，不提取人工挑选短语，不挑选提示词。
3. 直接复用既有真实候选裁剪的SigLIP2图片特征，不重新采集或重新检测。
4. 使用当前V4覆盖输入中的同一候选有效性条件：候选有效、存在有效地标关系和位置支持。只在这些候选中选取归一化图文向量余弦相似度最高者。
5. 先完成选择，再用私有目标坐标计算所选单一候选位置分布最高点到目标距离。无候选明确记为不可用；不算成选对。
6. 按TRAIN和内部DEV分别报告观测数、可用数、所选候选位置不超过20米的次数，以及同一观测A0位置正确次数。

边界：这只是单候选可行性检查，与当前A2多个候选组成的位置分布不同，不将数字当作严格匹配的策略优劣。没有混入A0、没有训练或校准启用判断、没有挑阈值或模型；不据此改变当前25轮训练及验证队列。完整指令可能被文字模型截断，结果不代表使用精确目标外观短语的上限。

本次循环在固定范围处理完毕并保存结果后结束；即使无效也如实保留，不在本次结果上尝试多个提示词直到变好。A2超过A0的目标仍需完整训练、独立检查及正式闭环评估证明。
