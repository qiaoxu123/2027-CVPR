# 四条失败指令的公开地标连接检查

范围仅限已查出的11条TRAIN观测所对应的4条指令。读取公开地图名称、既有指令与查询，用当前V4解析器和文字匹配器逐步检查。不运行网络、不改动当前实验；字符级完整覆盖只用于隔离文字匹配原因，不能替代实际BERT输入测试。

所有查询都有同名公开地图记录，没有查询因为完全找不到地图名称而失败。当前解析器输出13条地标记录：9条因同名对象不能唯一确定而不可连接，另外4条地图身份可连接但指令没有逐字提及该公开名称。13条记录包含同一查询的多个同名结果，不能当作13条独立指令或13个独立失败。

| 指令 | 确认的原因 |
|---|---|
| 7452，线路旁停车场 | 地图名称带CrossCountry前缀，指令省略前缀；公开身份可确定，但完整名称没有出现在指令中。 |
| 9353，Silver Street旁建筑 | Silver Street有5个同名公开记录，当前道路分组没有合并为可用引用；图书馆和The Anchor身份可确定，但指令写法没有逐字匹配。 |
| 11155，Sustainability Leadership旁建筑 | 公开地图有2个同名对象，身份歧义已足以阻断；指令另有断句差异，但本检查没有将其计作独立的首要失败。 |
| 21608，Abbey与Harvest交叉处停车场 | Abbey Road身份可确定，但指令写Abbey Street；Harvest Way有2个同名对象，身份歧义阻断。 |

结论：这一子集同时存在名称表达不一致和同名地图对象歧义。仅放宽逐字匹配不能恢复全部引用；任取最大轮廓或最靠近真实目标的对象会掩盖歧义，后者还会泄漏答案。后续应先核对同名道路的类型与几何连接性，解释为什么当前公开道路分组没有覆盖这些对象，并核对是否有可追溯的公开别名证据。不能直接把Abbey Street改成Abbey Road作为已确认事实。

这些是公开输入处理的已确认限制，不证明其解释了全部训练与内部验证差距。现有25轮训练、选择规则及后续验证保持冻结。A2超过A0仍未得到证明。
